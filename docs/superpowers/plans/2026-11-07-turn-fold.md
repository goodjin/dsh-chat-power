# 轮次折叠与当前轮限高 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 会话区按轮次工作：当前轮限高一屏、其余轮折叠成可展开的摘要条。

**Architecture:** 新增 DOM 控制器 `src/turn-fold.ts`：按宿主的 `data-chat-turn` 分组行、折叠历史轮（加属性 + 插摘要条）、按行测高给当前轮分摊限高并保持贴底。不移动宿主节点、不改宿主 React 结构。

**Tech Stack:** TypeScript、DOM API、CSS Module、Vitest（无 jsdom，纯逻辑 + 源码级约束）。

**Spec:** docs/superpowers/specs/2026-11-07-turn-fold-design.md

## Global Constraints

- 工作目录：`.worktrees/turn-fold`；按任务提交。
- 宿主契约：只用 `data-chat-turn`、`data-turn-start/end`、`[data-conversation-scroll]`；座位名一律查官方文档，不臆造。
- 不 reparent 宿主节点、不改写宿主属性以外的宿主元素；只加自己的属性、插自己的元素。
- 样式走宿主语义 token（`--dsw-alias-*`）；控件 6px 圆角、12px 辅助文字、图标 16px、点击区 ≥24px。
- 思考块折叠**不在本插件实现**（宿主设置项，README 写清路径）。
- 门禁：`npm test`、`npm run typecheck`、`npm run build`；产物 `lib/client.js` 随源码入库。

## Review Focus

1. 宿主重渲染后摘要条不得重复插入、不得残留孤儿节点；会话切换后不得把上一会话的折叠状态带到新会话。
2. 限高测量不得在每次 mutation 上引发布局抖动（限高只作用于当前轮，且必须有下限，不得把内容压成 0 高）。
3. 用户在限高容器内手动上滚后，流式更新不得把它强拉回底部。
4. 折叠不得吞掉当前轮的输入框、发送侦测（`send-watch`）与工具条；折叠状态不得影响宿主自己的滚动落地计算之外的任何行为。
5. 找不到宿主结构时必须安静退出，不能抛错影响插件其余部分启动。
