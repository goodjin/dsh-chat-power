# 轮次折叠与当前轮限高 — 设计

## 目标

会话区按“轮次”工作：一轮只占一屏，历史轮折叠成可展开的摘要条。

1. **思考块**：默认折叠、思考过程中展示、结束后自动折叠 —— 由宿主设置实现
   （设置 → 通用 → 工作步骤：「工作步骤收起时机＝回答结束后」「收起后显示的回复＝仅最终回答」）。
   本插件**零改动**这一条，只在 README 里写清怎么设。
2. **当前轮限高**：当前展开的一轮，总高不超过「视口高 − 输入框高 − 余量」；超出部分在轮内滚动，
   内容增长时保持贴底（用户手动上滚后不再抢滚动）。
3. **历史轮折叠**：新请求发出后，除当前轮外的轮次自动折叠成摘要条
   （轮次序号 + 时刻 + 首句摘要）；滚上去点摘要条可展开，展开态提供「收起」。

## 宿主契约（已核对）

- 每一行聊天 DOM 带 `data-chat-turn="<轮次号>"`，同轮多行同号；轮次首尾另有
  `data-turn-start` / `data-turn-end`。
- 滚动容器是 `[data-conversation-scroll]`，列在其内；宿主自带“跟随底部”与“回到底部”按钮。
- 宿主没有“整轮级”座位（`conversation.chat.*` 只有 node / flow / turnTail / reasoning.* 等），
  因此轮次级折叠只能在 DOM 层做。
- 宿主 React 拥有这些行。本插件**只加属性与插入自己的元素，不移动、不改写宿主节点**
  （与文件树装饰、选区浮层同一路子）。

## 方案

新增 `src/turn-fold.ts`（DOM 控制器）与 `src/turn-fold.module.css`（样式）：

- **观测**：`[data-conversation-scroll]` 上的 MutationObserver，按 `data-chat-turn` 把行分组为轮次；
  每轮记录首次出现时刻（作为摘要里的时间）与首句摘要。
- **当前轮**：轮次号最大的那一轮。新轮出现时，把之前所有轮次折叠。
- **折叠**：给该轮每一行加 `data-chat-power-collapsed`（CSS `display:none`），并在该轮第一行**之前**
  插入插件自己的摘要条（`data-chat-power-turn-strip`）。宿主重渲染若把摘要条冲掉，观察器补回。
- **展开**：点摘要条 → 去掉折叠属性、移除摘要条；展开态的历史轮在首行前插一枚右侧「收起」药丸。
- **限高**：不包宿主行（不 reparent），改为按行测高后分摊上限——当前轮各行高度合计超出可用高度时，
  把超出量优先压到该轮最高的行上（`max-height` + `overflow:auto`），使整轮合计 ≤ 可用高度。
  被限高的行若处于贴底状态，内容增长后把 `scrollTop` 置底。

## 数值

- 可用高度 = 视口高 − 输入框高 − 24px 余量（下限 240px）。
- 摘要条：12px 辅助文字、6px 圆角、1px 边框、12px 竖内边距；折叠态占一行，展开态药丸 24px 高。

## 错误与降级

- 宿主结构变化（找不到滚动容器 / 没有 `data-chat-turn`）→ 整个功能安静退出，不影响其它功能。
- 测量或插入失败 → 该轮退回原样（不折叠），并在控制台留一行。

## 验收

- 新请求发出后，历史轮变成摘要条、当前轮占主屏；滚上去能逐轮展开，也能再收起。
- 当前轮超过一屏时轮内出现滚动条，输入框与摘要条不被顶走；流式输出时内容自动贴底。
- 手动上滚后不再被强制拉回底部。
- 会话切换、标签切换、窗口缩放后状态自愈（摘要条不重复、不残留）。
